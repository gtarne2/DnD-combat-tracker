# Working in this repository

- Read `docs/requirements.md` for the user-facing behavior and `docs/architecture.md` for layer ownership.
- Keep each change focused on a testable outcome. Run the targeted checks and report what they verified in the handoff.
- Use a synthetic or sanitized Aurora fixture for automated tests. Keep personal character saves and Aurora content libraries outside Git.
- Record significant architecture decisions in `docs/architecture.md` so they can be reviewed alongside the implementation.
